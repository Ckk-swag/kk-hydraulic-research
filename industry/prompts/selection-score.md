## 内部计算：先识别类型，再给五轴独立打 0–10 整数分

内容类型七选一：

- `research_paper`：有研究问题、方法与结果的论文、预印本或技术报告；
- `dataset_release`：水位、流量、流速、含沙量、地形、遥感等数据集发布或重要更新；
- `software_release`：水动力、泥沙、水质等模型、水域机器人平台、开源代码或计算工具发布；
- `field_observation`：有可核对数据的现场监测、实验或水情观测结果；
- `engineering_project`：河口、河涌、排涝、防洪与生态工程的具体方案或结果；
- `policy_update`：正式发布的政策、技术标准、规划或管理要求；
- `tutorial_explainer`：可复用的方法、教程、对比评测或技术解读。

五轴：

1. `sig` 实质份量：是否改变对某一物理过程、模型方法、数据基础、工程决策或规范要求的认识。
2. `nov` 信息增量：是否给出明确的新结果、新数据、新方法、新参数、新边界或反常发现。
3. `cred` 证据强度：材料是否说明观测、实验、验证、对比、样本范围或正式文件；官方宣布能证明“发布”，不能自动证明效果。
4. `reson` 研究相关性：与河口潮汐、城市河涌、水动力或泥沙问题的贴近程度。相关的水质、洪潮和遥感方法可正常得分；泛水资源新闻降低此轴。
5. `act` 可迁移性：读者能否据此取得数据/代码、调整模型、复现实验、比较方法或更新选题与监测方案。

## 应正常评价的价值

- 潮汐边界、河口动力、泥沙冲淤、城市河涌流动与水质耦合研究中，有明确方法、数据和验证的结果。
- 可复用的网格生成、地形处理、边界设置、率定验证、不确定性分析，以及能说明适用条件与误差的对比研究。
- 新的公开观测数据、地形或遥感产品，尤其有覆盖范围、时间分辨率、获取方式和质量说明。
- 已正式发布并影响研究设计或工程实践的水利标准、政策和技术规程。
- 有明确工程尺度、观测或模型对照、成效与限制的河涌治理、河口整治、防洪排涝案例。
- 与主题紧密相关的预印本可正常评分，但“尚未同行评审”要在证据强度中体现，不能补写成正式发表。
- AI 水文预测、模型代理与数字孪生研究若提供可复核的数据、基线、误差指标和跨场景验证，可按方法价值正常评分；机器人观测、无人船测绘和水工巡检若报告测量精度、覆盖范围、运行约束或公开代码/数据，也可按研究或工程价值评分。

## 应压低的噪声

- 会议通知、征稿、招生、招聘、课程广告、泛宣传与重复转载，通常 `sig ≤ 2`。
- 只说“模型更精准”“治理取得成效”却没有研究设计、基线、数据、评估方法或结果的材料，`cred ≤ 3`。
- 只有一个地点的普通水情通报，缺少异常过程、可靠观测或对研究问题的启示，`sig ≤ 3`。
- 论文标题和摘要只换地区或数据集，方法与结果没有可解释增量时，`nov ≤ 3`；不可因 DOI 或期刊声望豁免。
- 广义“智慧水利”“数字孪生”宣传没有可复用模型、数据、指标或验证时，`act ≤ 2`。
- 只有机器人硬件参数、展会演示或“AI赋能”口号，没有水域应用、对照数据或实际测量/作业结果时，`cred ≤ 3` 且 `reson ≤ 2`。
- 对河口、河涌、水动力或泥沙研究没有清楚关联的水务商业新闻，`reson ≤ 2`。
- 日报、周报等多条新闻打包而没有单一焦点，`sig ≤ 3`。

标题与正文冲突时以正文为准。正文不足以识别研究对象、动作和阶段时，最终分数不高于 30。区分“观测到”“模拟得到”“作者推断”“机构宣布”和“已验证”，不得把弱证据升级。
